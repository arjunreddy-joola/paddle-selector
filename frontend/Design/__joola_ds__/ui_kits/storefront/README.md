# JOOLA Storefront UI Kit

A pixel-faithful recreation of the **joola.com** storefront.

## Files
- `index.html` — click-through demo: home → PDP → cart
- `Header.jsx` — marquee announcement bar + logo + mega-nav + search/cart icons
- `Hero.jsx` — full-bleed video/image hero with oversized display headline + black CTA
- `ProductCard.jsx` — tile with NEW badge, size/color swatches, price, quick-view
- `ProductGrid.jsx` — tabbed "PRO PADDLE SERIES" with Pro V / Pro IV / 3S
- `ProductDetail.jsx` — PDP: sticky gallery, buy column, size/color selectors
- `Footer.jsx` — dark footer with link columns + newsletter

## Limitations
- No cart persistence, no real checkout, no filtering on category pages.
- Table tennis, apparel, accessories pages are **not** recreated — only the pickleball flow.
- Icons: Lucide substitute (flagged in root ICONOGRAPHY).
- Fonts: Archivo + Inter substitute (flagged in root README).
